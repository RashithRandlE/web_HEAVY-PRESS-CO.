# Heavy Press Co. — Web Design Concept (V3)

> **Notice:** This project is a **concept web design demonstration** and is not an active commercial storefront or official product site.

---

## ⚡ Overview

**Heavy Press Co.** is an experimental, highly immersive brand website concept created to explore modern web design, high-impact typography, dark aesthetic layouts, micro-interactions, and 3D product visualizer integration.

---

## ✨ Features & Highlights

- **Hero & Motion Design:** Dark-mode editorial styling paired with high-contrast visuals and dynamic typography.
- **Interactive Flavor Cards / Bento Grid:** Clean modular layout presenting product lineup and attributes.
- **3D / Multimedia Assets:** Built to support interactive canvas and 3D glTF models for dynamic product previews.
- **Responsive Layout:** Tailored for seamless desktop and mobile viewing experiences.

---

## 🛠️ Tech Stack

- **HTML5 & Modern CSS3** (Custom layout grid, keyframes & animations)
- **JavaScript (ES6+)**
- **Assets:** Custom image textures and 3D glTF render integration
